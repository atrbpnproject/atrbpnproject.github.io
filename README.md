# atrbpnproject.github.io

Situs pendukung **Bale Ruang NTB** (https://atrbpnproject.github.io/baleruangntb/).

- `/.well-known/assetlinks.json` — verifikasi aplikasi Android (TWA) agar tampil layar penuh.
- `/regulasi/` — dokumen RDTR berukuran besar (PDF terkompres) yang dibuka dari menu Regulasi.
- `/tunggakan/` — dashboard rekap tunggakan SPOPP dari Excel ekstensi Rekap Tunggakan Kanwil.
- `/index.html` — mengalihkan ke aplikasi Bale Ruang NTB.
